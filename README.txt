INTEGRA_11 - Jurnal Kehadiran TEFA PPLG SMK N 11 Semarang
Create By Bimo Hadi Wijaya

Struktur folder:
  index.html          halaman utama
  css/style.css       seluruh tampilan
  js/app.js           logika (daftar, login, presensi, foto, ekspor PDF/Word, daftar siswa)
  js/logos.js         logo dalam bentuk data-URI untuk dokumen ekspor
  assets/             video-intro.mp4, logo-smkn11.png, logo-tefa.png

Cara pakai: buka index.html di browser, atau unggah seluruh folder ke hosting.
Catatan: ekspor PDF memakai pustaka jsPDF dari CDN (perlu internet).
Data akun tersimpan di browser (localStorage) per perangkat.
